Commandes a coller dans Google Cloud Shell.

Une seule origine est autorisee par projet, et c'est voulu : le bucket de
production n'accepte que le site deploye, celui de test n'accepte que le
serveur local. Une session locale ne peut donc pas ecrire dans le vrai coffre,
meme par erreur.

================================================================
PRODUCTION  (coffre-fort-ae72c)  --  origine https://tg24130.github.io
================================================================

Lien direct :
https://shell.cloud.google.com/?project=coffre-fort-ae72c

Coller le bloc ci-dessous en entier, puis Entree :

cat > cors.json <<'FIN'
[{"origin":["https://tg24130.github.io"],"method":["GET","PUT","POST","DELETE","HEAD"],"responseHeader":["Content-Type","Content-Length","Content-Range","Content-Encoding","Content-Disposition","Authorization","Range","x-goog-resumable","x-goog-meta-app","x-goog-meta-format","x-goog-meta-role"],"maxAgeSeconds":3600}]
FIN
gcloud storage buckets update gs://coffre-fort-ae72c.firebasestorage.app --cors-file=cors.json


================================================================
TEST  (coffre-fort-test)  --  deja fait le 28/08/2026
================================================================

A rejouer seulement si le port du serveur local change.

FIN
